# Contribution Strategy

To maximize successful contributions:

- Focus on small achievable tasks
- Follow each repository's coding conventions
- Comment on issues before starting work
- Keep pull requests focused and clean
- Respond quickly to review feedback
- Ensure CI checks pass before submitting PRs
